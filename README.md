# 回光百日 · 太乙金華宗旨

依《太乙金華宗旨》（呂祖著，清刊本）編成的百日築基實修 PWA。單檔 HTML，離線可用，所有紀錄只存在本機瀏覽器。

**線上使用**：https://kftseng2oo1.github.io/ginfa/

## 功能

**今日** — 回光輪進度環（十旬刻度隨完成度亮起）、本旬功課要領、今日一訣、一鍵起香。

**靜坐** — 依時長比例走五段引導：調攝身心 → 垂簾定端 → 繫念緣中 → 心息相依（佔 68%）→ 收功。Web Audio 合成引磬，起香三通、換段一聲、收功三通。坐中可隨時叫出「止觀四步」對治雜念。

**心法** — 41 張要訣卡，正面原文、背面白話與出處，分十一類。Leitner 間隔複習：「已熟」1 → 3 → 7 → 21 → 60 天，「再看」歸零。

**歷程** — 完成度、平均時長、證驗次數；依旬分段的百日圖；昏沉／散亂近二十座柱狀；覺受標籤統計；溫養隨筆時間軸。

**更多** — 坐香時長、引磬開關、配色（夜天金華／子夜極簡）、回光差謬三條歧路常備提醒、JSON 備份與 CSV 匯出。

## 技術

- 單檔 `index.html`，ES5 語法，無框架、無外部資源
- iOS WebView 相容：不用 `alert()` / `confirm()`，全部 `addEventListener`
- 計時以時間戳為準，背景節流或凍結後回前景仍準確
- Wake Lock API 防止坐中螢幕休眠（不支援則自動略過）
- localStorage 儲存，失敗時退回記憶體，不會中斷使用
- Service Worker 快取優先、背景更新

## 部署

推到 GitHub 後開 Settings → Pages → Source 選 `main` / `root` 即可。

改版時記得把 `sw.js` 裡的 `VERSION` 加一，舊快取才會換掉。
